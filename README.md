# PENDING — Chapter 0 (demo)

Play in the browser: https://feixqemn.github.io/pending-demo/

About 10–15 minutes. Chinese / English — press **Y** at any time to switch.
约十到十五分钟。中文 / English，任何时候按 **Y** 切换。

**Controls / 操作**　Space / Enter confirm 确认 · Backspace / Esc back 返回 · X refresh 刷新 · Arrow keys move 移动 · Y language 语言 · − / = volume 音量 · M mute 静音

Progress is saved in your browser. 进度保存在当前浏览器里。

This repository only hosts the built web version. Made with Godot Engine; licenses for the engine and the bundled fonts are in [`LICENSES/`](LICENSES/).
